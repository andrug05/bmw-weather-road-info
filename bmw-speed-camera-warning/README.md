# BMW Speed Camera Warning

Отдельное приложение предупреждения о камерах контроля скорости для BMW MGU ID7.

## Принципы проекта

- Самостоятельное OAP-приложение со своим package ID, манифестом, ACL и сборкой.
- Не использует исходники, runtime, сетевой код или зависимости Weather 0.2.7.
- Не изменяет и не заменяет существующее приложение Weather & Road Info.
- Отслеживает положение автомобиля и расстояние до камер.
- Голосовые предупреждения должны использовать штатный BMW Readout SOME/IP API.
- Целевой сценарий: приложение работает в фоне, штатная навигация BMW остаётся на переднем плане.
- Не управляет громкостью радио и не подменяет штатный аудиоканал.

## План разработки

1. Изучить реализацию и разрешения Readout в штатном фоновом приложении BMW `trigger_service`.
2. Создать минимальный OAP-прототип: регистрация Readout-клиента и тестовая фраза.
3. Проверить произнесение сначала на переднем плане, затем при фоновой работе и активной штатной навигации.
4. Добавить получение координат, базу камер и расчёт направления/дистанции.
5. Добавить экран настроек и сборку отдельного пакета для MGU ID7.

## Статус

Начальная структура проекта. Реализация приложения и сборка пока не добавлены.
